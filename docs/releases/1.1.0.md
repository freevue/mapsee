# 맵시 1.1.0

연속된 의미 중복·반응형 줄바꿈·검사용 문구와 로그 잔여물 검사를 추가합니다. 캡처 위의 격자·측정선으로 간격과 정렬을 보여 주며 다이얼로그 등 영역의 상태별 화면과 전환을 연결합니다. 1.0.0과 호환되는 기능 추가입니다.

## 추가 기능

- **연속된 의미 중복:** 선택한 탭 이름을 본문 제목으로 반복하거나 제목·설명·상태·행동이 새 정보 없이 이어지는지 확인합니다. 필요한 제목 구조·접근성 표현·화면별 맥락은 보존합니다.
- **반응형 줄바꿈:** 짧은 이름의 글자 단위 분리·고립된 마지막 단어·아이콘 분리·줄 수에 따른 정렬 문제를 실제 화면과 부모 너비로 확인합니다. 자연스러운 여러 줄을 일괄 금지하지 않습니다.
- **검사용 잔여물:** 제품에 남은 임시 검사 문구·표식·진단 로그·중단점을 오류로 보고합니다. 정상 안내·운영 로그·개발 전용 진단은 확인한 용도·실행 경계로 구분하며 작성자가 AI인지 추측하지 않습니다.
- **격자 시각화:** `render-grid.mjs`가 원본 PNG와 실제 경계 JSON에서 별도 SVG를 생성합니다. 간격 배수·정렬·기준점 관계를 구분하며 PNG·입력 해시와 측정값을 JSON으로 제공합니다.
- **영역·상태별 검사:** URL·호출부·다이얼로그/드로어 등의 영역·상태·화면 조건을 연결합니다. 기본·처리 중·오류·완료의 캡처와 열기·닫기·재시도 흐름을 구분합니다.

lint는 결과를 보고하며 제품·DESIGN·wiki를 자동 수정하지 않습니다. 검사 중에도 제품 소스·화면에 문구·로그·격자를 심지 않습니다. setup·document는 해당 기준의 조건·예외·결정 상태를 기존 문서에 연결합니다.

## 격자 도구

```bash
node <lint 스킬 경로>/scripts/render-grid.mjs 측정.json 새결과.svg
```

기본 간격은 4 CSS px이며 프로젝트의 채택 여부·기준점·오차·적용 대상을 명시합니다. 미채택 기준은 review입니다. 종료 코드 0은 산술 차이 없음, 2는 배수·정렬 차이, 1은 입력·실행 오류입니다. 기존 출력은 덮어쓰지 않습니다. [입력과 해석](../../plugins/mapsee/skills/lint/references/grid.md), [영역별 절차](../../plugins/mapsee/skills/lint/references/surfaces.md)를 확인합니다.

## 설치와 호환성

기존 Codex 설치는 다음 순서로 갱신합니다.

```bash
codex plugin marketplace upgrade mapsee
codex plugin add mapsee@mapsee
```

Node.js 20 이상을 사용합니다. 플러그인 이름·세 스킬·보고서 schemaVersion 1·두 검사 축·기존 산식을 유지합니다. 새 격자 JSON은 최종 보고서를 대체하지 않는 측정 근거입니다. [1.x 호환성 계약](../../plugins/mapsee/COMPATIBILITY.md)을 따릅니다.
