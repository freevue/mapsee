# 맵시 0.6.1 배포 후보

2026-11-23에 준비한 패치 후보의 기록입니다. 이후 기능 보강은 [0.7.0 후보](0.7.0.md)로 이어집니다. 배포 방식은 Git 마켓플레이스이며, 이 준비 문서와 로컬 패키지는 원격 반영·태그·GitHub Release 발행을 뜻하지 않습니다.

## 변경 내용

- 공용 컴포넌트가 필요한 위치의 일반 DOM·스타일 대체를 검사합니다. import·클래스·data 속성 이름만으로 재사용을 인정하지 않습니다.
- 별칭·재내보내기·앱 래퍼의 실제 렌더 경로를 확인합니다. 구현 내부 DOM·허용된 레이아웃·대응 공용 구현이 없는 역할을 일괄 위반으로 만들지 않습니다.
- 기존 영역의 미확정 기준은 `review`로 남깁니다. 일반 DOM 대체와 변형 오용, 정상 사용과 예외를 구분하는 정적 시나리오 10개를 추가했습니다.
- 보고서 검증기에 `component-reuse` 선택을 추가했습니다. 인자를 생략하면 기존 `design-audit` 17개 시나리오를 사용합니다.
- 명시적으로 허용된 native 역할의 근거 있는 적용 제외를 검증기가 오판하는 문제를 수정했습니다.

## 호환성

플러그인 이름 `mapsee`, 스킬 이름 setup·document·lint, 두 검사 축과 보고서 `schemaVersion=1`을 유지합니다. 기존 검증 명령은 그대로 사용할 수 있습니다. 두 플랫폼의 플러그인 버전은 모두 `0.6.1`입니다.

lint는 보고 전용이며 제품 코드·DESIGN·wiki를 자동 수정하지 않습니다. 이번 패치는 Codex가 기준과 소스를 읽는 검사 지침과 검증 자료의 보완입니다. 범용 DOM·JSX 분석기를 추가한 것은 아닙니다.

## 검증 근거

| 범위 | 결과와 한계 |
| --- | --- |
| 검사기·패키지 단위 검사 | 테스트 31개. 종료 코드·입력 보존·오탐·누락·예외·스킬 자료를 확인합니다. |
| Codex 정적 판정 10개 | 불일치 4·일치 2·적용 제외 3·판단 필요 1·미측정 0입니다. 기대 판정과 검증기를 제공하지 않은 수행이며 원본 근거를 보존했습니다. |
| 판정 근거 재사용 | 이전 수행의 입력 17개가 후보 소스와 동일할 때만 재사용합니다. 버전 문자열만으로 동일성을 판단하지 않습니다. |
| 패키지 준비 | 마켓플레이스 두 개·플러그인·문서·테스트를 포함한 소스 배포본을 만들고 파일 해시·형식·참조를 대조합니다. |

상세 결과와 검사 절차는 [검증 기록](../verification.md)과 [재사용 회귀 절차](../verification-plan.md#공용-컴포넌트-재사용의-정적-회귀)에 있습니다. 실제 React 타입·빌드·렌더·접근성 수용은 이 정적 회귀에서 새로 검증하지 않았습니다. Claude의 모델 수행도 이번 패치 검증 범위에 포함하지 않습니다.

## 원격 반영 단계

1. 준비한 변경을 검토하고 커밋합니다. 일반 Git push로 main에 반영합니다.
2. 그 커밋의 GitHub 테스트 결과를 확인합니다. 로컬 결과를 원격 CI 성공으로 표시하지 않습니다.
3. Codex의 기존 Git 마켓플레이스를 새로고침하고 `mapsee@mapsee`를 업데이트합니다. 설치 버전·활성화 상태와 원격 소스의 파일 동일성을 확인합니다.

이 후보의 최초 패키지 준비에서는 기존 0.6.0 설치본을 변경하지 않았습니다. 이후 로컬 설치 상태와 실제 적용은 각 버전의 검증 기록을 따릅니다. 원격 반영 후에는 README의 설치 절차를 사용합니다.
