# 맵시 1.0.0

공용 컴포넌트 사용과 페이지 간 일관성을 검사하는 맵시의 Codex 우선 정식 배포입니다. 공개 0.6.0 이후 준비한 0.6.1~0.12.0의 검사·setup·근거 검증을 함께 배포합니다. 0.12.0에서 검사 동작을 추가로 변경하지 않고 버전과 공개 호환 범위를 정리했습니다.

## 포함하는 기능

- 공용 컴포넌트 대신 일반 DOM을 구성한 경우, 별칭·래퍼·분기·props 전달·복합 구성을 구분합니다.
- 컴포넌트 선택·배치 이유, 스타일 덮어쓰기, 간격·여백·중첩 라운드와 다른 페이지의 동등 역할을 검사합니다.
- 연속 상태 전환·오류 복구·배치 영역·준비된 캡처·부유 UI·키보드·환경 변화의 실제 근거를 연결합니다.
- 토큰 역할·별칭·활성 fallback, 표시·native/ARIA 상태·연결 콘텐츠와 강제 색상에서의 선택·초점을 대조합니다.
- 대상 목록·근거 연결·문제 그룹·이력 비교·변경에 따른 재검사 제안과 원본 묶음·캡처 준비 검사 도구를 제공합니다.
- setup은 기존 DESIGN·컴포넌트 설명의 누락·최신성·충돌을 점검하고 요청 범위에서 보완합니다. 같은 입력으로 재실행할 때 중복·불필요한 변경을 피합니다.

lint는 결과만 보고합니다. 제품·디자인 문서·wiki를 자동 수정하지 않으며 후속 작업은 bab·pstack 또는 사용자가 정합니다. 프로젝트의 색·간격·금지 클래스를 맵시의 공통 기준으로 강제하지 않습니다.

## 호환성과 설치

이름 mapsee, 세 스킬, 보고서 schemaVersion 1과 두 축·기존 산식을 유지합니다. [1.x 호환성 계약](../../plugins/mapsee/COMPATIBILITY.md)에 공개 필드·CLI·종료 코드·버전 정책을 명시했습니다. 기존 보고서에 강화 연결이 없다는 이유로 새 필드를 요구하지 않습니다.

```bash
codex plugin marketplace add freevue/mapsee
codex plugin add mapsee@mapsee
```

기존 Codex 설치는 다음 순서로 갱신합니다.

```bash
codex plugin marketplace upgrade mapsee
codex plugin add mapsee@mapsee
```

Node.js 20 이상이 CLI 실행에 필요합니다. Claude용 패키지도 포함하지만 실제 Claude 실행은 미검증입니다.

## 검증과 남은 범위

릴리스 검증·설치본·원격 상태는 [1.0.0 검증 기록](../verification/1.0.0.md)에 구분합니다. 엔강대의 [0.12.0 실제 화면 검사](../verification/0.12.0.md)는 원본과 검사 지침·스크립트의 동일성을 대조해 재사용하며 새 브라우저 실행으로 표시하지 않습니다.

엔강대의 강제 색상 선택·초점 검토 3개와 이전 미재검사·실제 모바일 키보드 미측정은 그대로 남깁니다. 실제 Windows·화면 읽기 음성·전체 게임/DB·운영 수용·독립 모델 정확도는 이번 정식 버전의 검증 범위가 아닙니다.
