# 맵시 0.8.0 배포 후보

대상 누락 확인·다른 URL의 페이지 비교·스타일 재정의·이전 결과 비교를 추가한 마이너 후보의 기록입니다. 이후 보강은 [0.9.0 후보](0.9.0.md)로 이어집니다. [0.7.0 기록](0.7.0.md)과 로컬 패키지는 보존했습니다.

## 변경 내용

- 발견한 페이지·사용처·상태를 scope.inventory와 검사 ID로 연결합니다. 집계기는 확인·미검사·범위 밖을 적합률과 별도로 계산하고 누락된 결과·미검사 대상을 숨긴 complete를 거부합니다.
- 같은 URL의 스텝과 다른 URL의 페이지 비교를 구분합니다. 동등한 역할·조건을 연결하고 화면별 밀도·크기·읽기 전용 등의 차이를 일괄 위반으로 만들지 않습니다.
- 공용 컴포넌트를 사용해도 호출부 CSS가 고정 높이·여백·색·비활성 계약을 깨뜨렸는지 확인합니다. plain·너비·배치의 허용 범위와 구분하는 시나리오 8개를 추가했습니다.
- compare.mjs가 원본 보고서를 읽어 새 불일치·해결·유지·미재검사·기준 변경을 분류합니다. 검사 ID가 빠지거나 조건·대상이 불명확하면 해결로 표시하지 않습니다.
- setup은 미결정 기준을 적용 역할·조건·예외·기대 결과와 선택할 사항으로 구체화합니다. 모달/비모달과 실제 중첩 표면을 구분하고 제안을 자동 채택하지 않습니다.

## 호환성

플러그인 이름 mapsee, setup·document·lint, 두 검사 축과 report schemaVersion 1을 유지합니다. inventory와 inventorySummary는 선택 정보입니다. 목록이 없는 이전 보고서도 읽으며 이전 결과에서 누락 확인을 했다고 추정하지 않습니다.

비교 출력은 mode=report-comparison입니다. 정상 비교는 불일치가 남아도 종료 코드 0이며 입력 오류는 1입니다. 같은 프로젝트인지와 기준의 실제 동일성은 원본을 읽은 에이전트가 확인합니다. 비교 도구는 보고하지 않은 변경이나 근거의 진위를 추론하지 않습니다.

## 검증과 적용

테스트 47개와 설치본의 독립 정적 판정 8개를 확인했습니다. 엔강대의 홈·대진표에서 기존 항목 11개를 다시 수행하고 5개를 추가했습니다. 기존 상태는 유지됐고 생성 폼 버튼의 font-size·padding에 새 검토 항목이 남았습니다. 상세 근거와 범위는 [0.8.0 적용 결과](../verification/0.8.0.md)를 따릅니다.

Codex의 mapsee@mapsee를 로컬 0.8.0으로 갱신했습니다. 이전 로컬 네임스페이스는 비활성 상태와 설치 자료를 유지했습니다. 영구 Git 마켓플레이스 주소는 유지합니다. 커밋·푸시·공개 원격 반영·원격 CI·Claude 모델 실행과 운영 수용은 이 로컬 적용 결과에 포함하지 않습니다.
