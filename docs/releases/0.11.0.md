# 맵시 0.11.0 배포 후보

캡처 준비 상태, 모바일 키보드·표시 영역과 툴팁·메뉴의 연결·가림·유지를 보강했습니다. [0.10.0](0.10.0.md)과 이전 후보·검증 자료는 보존합니다.

## 변경 내용

- setup은 기존 가이드에서 캡처 대상·조상·자산·기대 상태와 관찰 조건, 모바일 키보드 전후의 접근·고정 UI, 부유 UI의 연결·유지·닫기를 확인·보완합니다.
- check-readiness.mjs는 준비 기록 version 1의 실제 연속 구간·최대 관찰 간격·경계·관련 애니메이션·조상 불투명도·선택 자산을 검사합니다. ready만 종료 코드 0이며 pending·transition은 2, 형식·실행 오류는 1입니다.
- 모든 opacity 1·모든 자산 성공을 강제하지 않습니다. 의도한 50% 상태와 실패 자산의 대체 화면은 원본 기준으로 검사합니다. 전환 자체의 수집을 정지 비교 완료로 승격하지 않습니다.
- 모바일은 실제 키보드·합성 표시 영역·표시 확인 불가를 구분합니다. 툴팁·메뉴는 기준 요소와의 관계·가림·실제 입력·유지·닫기를 확인하고 native title·모달과 다른 패턴으로 검사합니다.

## 검증과 적용

테스트 76개와 세 스킬의 형식 검사를 수행했습니다. 실제 수집 중 발견한 큰 관찰 공백을 회귀로 추가해, 시작·종료 두 장만으로 연속 관찰을 완료 처리하지 않는지 확인했습니다.

가상 화면에서는 이미지 대기와 부모 페이드를 pending, 최종 실제 관찰을 ready로 구분했습니다. 도움말의 정상 유지·Escape 닫기와 포인터 이동 시 사라지는 위반을 구분하고 프로그램 스크롤 후 기준 요소 관계도 확인했습니다. 이는 엔강대의 판정이 아닌 검사 검증 자료입니다.

엔강대의 조상·글꼴을 포함한 캡처 준비 표본은 ready입니다. 합성 390×500px에서는 Tab 이동에 따라 카드 내부 영역이 스크롤되고 제출 행동에 접근했습니다. 실제 OS 키보드는 미측정으로 남겼고 현재 제품 보고서는 incomplete입니다. [적용 검증](../verification/0.11.0.md)에 실제·가상 결과와 범위를 기록했습니다.

## 호환성과 남은 범위

보고서 schemaVersion 1·기존 두 축·산식과 원본 묶음 version 1을 유지합니다. 준비 기록은 별도 파생 자료이며 제품 코드·기준·보고서를 자동 변경하지 않습니다. 준비 도구는 제공된 기록만 검사하며 범용 브라우저 실행기가 아닙니다.

Codex 설치본은 로컬 0.11.0입니다. 실제 모바일 기기·OS 키보드·물리 터치·전체 툴팁/메뉴 사용처·전체 라우트·다른 URL 비교·Claude·독립 모델 평가·실제 DB·원격 CI·운영 수용은 이번에 확인하지 않았습니다. 커밋·푸시·공개 배포 전 로컬 후보입니다.
