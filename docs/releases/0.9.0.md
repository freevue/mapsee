# 맵시 0.9.0 배포 후보

대상·상태·근거 연결, 과업 영향·공통 원인, 반응형 경계 검증과 변경 영향의 재검사 제안을 보강했습니다. [이전 0.8.0](0.8.0.md)과 패키지·검증 자료는 보존합니다.

## 변경 내용

- 새 수집은 bindingVersion 1로 inventory 대상·상태·조건과 판정·수집 ID·기준 식별자를 대조합니다. 다른 URL·기본 상태의 근거로 완료 처리하는 것을 방지합니다. 미연결 대상과 연결 오류는 pending으로 남습니다.
- 문제는 triageVersion 1의 공통 원인·소유 위치·실제 과업 영향으로 묶습니다. blocking·degraded·presentation·undetermined를 판정 상태와 구분하고 미분류와 영향 미정도 남깁니다.
- 전환점 직전·해당 값·직후, 긴 이름·오류·확대 조건을 실제 검증 표본으로 연결합니다. 기본·처리 중·오류·다른 확대 방법을 혼동하지 않습니다.
- retest.mjs가 확인된 사용처 관계와 변경 파일을 대조해 재검사 목록을 제안합니다. 미연결 변경·표본 밖 영향을 표시하고 검사 실행이나 기존 필수 검증 축소를 승인하지 않습니다.

## 호환성과 한계

플러그인 이름 mapsee, setup·document·lint, 두 검사 축과 report schemaVersion 1을 유지합니다. 새 bindingVersion·triageVersion의 검증에는 0.9.0 집계기를 사용합니다. 이전 보고서도 읽지만 새 연결 검증을 통과한 것으로 표시하지 않습니다.

메타데이터 검사는 파일·이미지·수집자의 진위를 자동 보증하지 않습니다. 수행자가 원시 자료·내용 해시·실제 화면을 대조한 범위를 밝힙니다. 영향 분류는 새로운 품질 점수나 기준의 확정 여부가 아닙니다. 재검사 도구는 에이전트가 추적한 파생 관계를 사용하며 범용 소스 분석기가 아닙니다.

## 검증과 적용

테스트 59개가 통과했습니다. 정답을 제공하지 않은 Codex는 합성 측정보고서에서 확인 가능한 불일치 1개와 근거 없는 측정 2개를 구분했습니다. 두 항목을 미측정으로 남기고 원본을 보존했습니다.

엔강대에서는 기존 16개를 새로 수집하고 5개를 추가했습니다. 1024px·640px 경계, 126자 이름, 320 CSS px의 오류·버튼, 실제 200% 핀치와 Tab 이동을 확인했습니다. 과거 검토 3개는 유지됐습니다. 상세 내용은 [0.9.0 검증 기록](../verification/0.9.0.md)에 있습니다.

Codex의 mapsee@mapsee는 로컬 0.9.0으로 갱신했습니다. 영구 Git 마켓플레이스 주소와 비활성인 이전 로컬 설치 자료는 유지합니다. 이 후보의 커밋·푸시·공개 원격 반영·CI·Claude 모델 실행과 운영 수용은 별도입니다.
