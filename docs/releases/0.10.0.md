# 맵시 0.10.0 배포 후보

좁은 부모 영역에서의 컴포넌트 사용, 연속 상태 전환과 보존한 근거 원본 검증을 보강했습니다. [0.9.0](0.9.0.md)과 이전 후보 자료는 보존합니다.

## 변경 내용

- setup은 기존 가이드에서 부모 영역·역할에 따른 크기·variant·배치, 중단·재시도·늦은 응답의 정책과 단계별 기대 결과를 확인·보완합니다. 현재 구현을 확정 기준으로 승격하지 않습니다.
- lint는 뷰포트와 실제 부모 content box를 구분하고, 같은 화면 너비에서도 좁은 모달·카드·사이드바의 사용을 대조합니다. CSS container query나 고정 크기를 강제하지 않습니다.
- 실패→수정→재시도→성공, 대기 중 닫기와 이탈 후 지연 응답은 실제 조작·응답 순서를 기록합니다. 최종 화면 하나로 전체 흐름을 완료 처리하지 않습니다.
- verify-evidence.mjs가 수집·기준 원본의 SHA-256, JSON Pointer 내용과 보고서의 연결을 검사합니다. 입력을 보존하며 원본 문제는 종료 코드 2, 실행·형식 오류는 1로 구분합니다.

## 검증과 적용

테스트 69개로 기존 집계와 연결을 유지하고 새 원본 검증의 정상·변조·누락·잘못된 위치·바깥 경로·입력 보존을 확인했습니다. 미측정을 원본 검사 통과로 승격하지 않는 것도 검사합니다.

현재 Codex가 설치본을 읽고 엔강대 고정 커밋의 실제 화면을 검사했습니다. 같은 1440px에서 본문 콘텐츠 1088px·모달 448px, 390px에서 모달 콘텐츠 310px을 확인했습니다. 실패 후 재시도·합성 성공, 모달의 대기 중 Escape 차단·실패 후 닫기, 이탈 뒤 도착한 조회 응답의 영향도 확인했습니다.

새 표본 7항목은 일치 6·검토 1입니다. 보존한 캡처 6개·기준 6개·보고서 참조 10개가 원본 검사를 통과했습니다. 대진 주요 버튼의 역할별 글자·여백 기준은 계속 검토 대상입니다. [적용 검증](../verification/0.10.0.md)에 표본·수치·원본과 한계를 기록했습니다.

## 호환성과 남은 범위

플러그인 이름과 setup·document·lint, 보고서 schemaVersion 1·기존 두 축·산식은 유지합니다. 원본 묶음 version 1은 별도 파생 자료이며 기존 보고서를 자동 변환하거나 수정하지 않습니다. 파일 동일성은 수집자의 진위·이미지 의미·판정의 타당성을 보증하지 않습니다.

Codex mapsee@mapsee는 로컬 0.10.0입니다. 별도의 독립 모델 평가는 이번에 실행하지 않았습니다. 이전 0.9.0의 다른 표본·전체 라우트·실제 DB 저장·동시 요청 응답 역전·Claude·원격 CI·운영 수용은 이번 검증에 포함하지 않았습니다. 커밋·푸시·공개 원격 반영 전인 로컬 후보입니다.
