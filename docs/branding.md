# 맵시 아이콘

영문 표기는 `mapsee`, 한글 이름은 `맵시`입니다. 사용자는 2026-11-16에 웹페이지가 셔츠를 입은 세 번째 시안을 확정했습니다. bab의 밥그릇에서 문서가 나오는 그림처럼, 옷 속에서 웹페이지가 드러나는 비유로 화면의 맵시를 표현합니다.

[확정 아이콘](../plugins/mapsee/assets/icon.png)은 내장 이미지 생성 도구로 만든 PNG입니다. [두 번째 시안](assets/icon-v2.png)을 입력으로 사용해 눈을 제거하고, 브라우저 창에 옷깃과 소매가 있는 셔츠를 입혔습니다. 이전 시안은 기록용으로 보관하며 배포 플러그인에는 확정 아이콘만 포함합니다.

README와 Codex의 로고·입력창 아이콘은 같은 파일을 참조합니다. 픽셀 크기별 가독성과 실제 클라이언트의 표시 확인은 아이콘 채택과 별도의 검증입니다.

## 세 번째 시안 생성 프롬프트

```text
첨부된 mapsee(맵시) 아이콘을 사용자의 새 방향으로 수정해 주세요. 네이비 둥근 사각 타일과 크림색 브라우저 창이라는 제품군 스타일은 유지하고, 눈 모양은 완전히 제거합니다. 새로운 핵심 아이디어는 ‘웹사이트가 옷을 입고 맵시를 갖춘 모습’입니다. 정면의 크림색 브라우저 창이 단정한 청록색 셔츠를 실제로 입고 있는 하나의 귀여운 사물 아이콘을 그려 주세요. 브라우저 창 상단에는 창 조작을 나타내는 작은 점 세 개와 간결한 UI 블록이 보여 웹페이지라는 것을 바로 알 수 있어야 합니다. 브라우저 창의 아래 절반을 감싸는 청록색 셔츠 몸판, 양옆으로 짧게 나온 소매 두 개, 목 부분의 분명한 크림색 접힌 셔츠 옷깃 두 개를 표현합니다. 브라우저 창 자체가 셔츠 안으로 들어가 있고 옷깃 위로 웹페이지가 솟아 있는 통합 실루엣입니다. 사람이나 얼굴, 팔, 손, 마네킹은 없습니다. 셔츠를 창 옆에 따로 놓지 말고 창이 옷을 입은 것으로 읽혀야 합니다. 관련 플러그인 bab의 아이콘이 밥그릇에서 문서가 나오는 비유인 것처럼, 맵시는 옷 속에서 웹페이지가 나오는 직접적인 시각적 비유입니다. 단정한 평면 벡터 일러스트 느낌, 굵고 둥근 선, 큰 단순 형태, 작은 아이콘에서도 알아보기 쉬운 최소한의 세부 묘사. 기존 네이비 바탕·아이보리 창·청록 의상으로 절제된 세 색 구성. 옷 단추는 있어도 최대 두 개. 타일 바깥은 실제 투명 배경. 글자·텍스트·워드마크·눈·돋보기·체크리스트·리본·매듭·장식 반짝임·사실적 천 질감·목업·입체 효과·그라데이션 없이 완성된 아이콘 한 개만 출력해 주세요.
```

## 두 번째 시안 생성 프롬프트

```text
첨부된 맵시 아이콘을 완전히 재구성해 주세요. 기존 추상 옷깃 모양은 사용자가 의미를 알아보기 어렵다고 했으므로 실루엣과 소재를 바꿉니다. 새 브랜드 영문 이름은 mapsee, 한국어 이름은 맵시이며 디자인 화면을 보고 점검하는 플러그인입니다. 핵심 심볼을 직관적인 두 사물 ‘작은 UI 화면 + 그 화면을 살펴보는 눈’으로 바꿔 주세요. 커다란 아이보리색 UI 창 안에 가지런한 화면 블록 두세 개가 보이고, 창의 오른쪽 아래 앞에는 명확하고 친근한 눈 모양 하나가 겹쳐 있습니다. 창과 눈을 합친 아주 단순한 하나의 그림 아이콘으로 구성하고 작은 32px에서도 읽히게 해 주세요. 관련 플러그인 bab은 어두운 남색의 둥근 사각 바탕에 호박색 밥그릇과 크림색 체크 문서를 그린 직관적인 평면 아이콘입니다. 같은 제품군에 어울리는 평면 벡터 일러스트 느낌, 남색 둥근 사각 타일, 아이보리 UI 창과 부드러운 청록색 눈의 절제된 대비로 해 주세요. 정면, 굵고 둥근 윤곽, 균형 잡힌 여백. 바탕 타일 바깥은 실제 투명 배경. 텍스트·글자·지도·핀·추상 매듭·리본·사실적인 눈·입체 효과·그라데이션·장식 반짝임·목업 없이 아이콘 한 개만 만듭니다.
```
