## 준비 상태와 수집 보완

가상 이미지의 고정 경계가 유지돼도 부모가 페이드 중이고 이미지가 대기 중이면 pending으로 나뉘었습니다. 최종 관찰은 8회·약 181ms, 최대 간격 약 28ms로 해당 자료의 120ms 이상·80ms 이하 간격 조건을 통과했습니다. 이미지·부모·상위 표면의 opacity와 이미지 성공을 함께 확인했습니다.

초기 requestAnimationFrame 수집 일부는 두 관찰 사이가 약 1초였고, 새 호출의 실제 뷰포트도 계획한 값과 달랐습니다. 최초 자료를 보존하고 이를 ready로 사용하지 않았습니다. 최대 관찰 간격의 회귀를 추가한 뒤 각 호출의 실제 뷰포트를 다시 확인했습니다. Node에서 반복한 실제 DOM 관찰로 최종 자료를 수집했습니다. 큰 공백을 성공 조건에 맞춰 줄여 기록하거나 임계값을 완화하지 않았습니다.

엔강대는 form과 전환 소유 조상을 포함한 7개 식별자·선택한 Ria/Wanted Sans 로딩을 확인했습니다. 최종 8회·약 161ms·최대 간격 약 24ms의 기록은 ready입니다. 이 준비 결과를 제품 적합률 항목으로 더하지 않았습니다. 390×844의 준비 표본과 390×500의 조작 과정은 별개의 조건입니다.

도구의 ready는 선택한 구간·요소·자산 기록의 정합성입니다. 전체 페이지·미래 안정성·실제 글리프 전체·수집자의 진위나 제품 품질 수용을 보증하지 않습니다.

## 실제 키보드와 합성 표시 영역

입력 전후 visualViewport는 390×844·scale 1로 유지됐습니다. 데스크톱 브라우저에서 실제 OS 키보드 표시를 확인하지 못해 계획한 키보드 항목은 not-measured입니다. focus 성공과 작은 화면을 키보드 재현으로 완료 처리하지 않았습니다.

합성으로 높이를 500px로 바꾸면 제출 행동은 처음 화면 아래에 있었습니다. Tab 이동 후 내부 스크롤 167px이 발생했고 제출 버튼의 경계는 y=340.125~388.125로 표시 영역에 들어왔습니다. 입력한 이름도 유지됐습니다. 이는 낮은 화면에서 카드 전체에 접근하는 기존 계약의 표본입니다. 실제 키보드·안전 영역·고정 하단 UI의 전체 수용과 구분합니다.

## 집계·원본·setup

엔강대 보고서는 두 항목 중 일치 1·미측정 1입니다. 적합률은 `1/1 = 100%`, 커버리지는 `1/2 = 50%`이고 실행 상태는 incomplete입니다. 실제 키보드 미측정으로 대상 1개가 pending입니다. 다른 URL의 대응 역할 비교는 이번 표본에 없어 페이지 일치율·커버리지는 null입니다.

가상 화면·엔강대 보고서를 각각 설치본 summarize.mjs·verify-evidence.mjs로 검사했습니다. 기준의 고정 복사본·원시 JSON·해시·내부 내용·보고서 연결을 대조했습니다. 원본 검사 통과가 키보드 미측정이나 전체 실행 상태를 변경하지 않았습니다. 이전 0.10.0의 7개 항목은 미재검사이며 해결 0입니다. 이력 도구의 미재검사 총 8개에는 새 키보드 미측정 1개도 포함됩니다. 현재 성공 판정을 추가 검사로 분류한 것은 1개입니다.

setup은 별도 가상 문서에서 기존 사용 가이드 1개에 확정된 수집 조건·부유 UI 동작·실제 기기 범위와 출처를 보완했습니다. 같은 입력으로 재검토한 후 문서·화면 3개 해시가 같았습니다. 이 자료의 시간·허용 오차를 맵시 공통 기준으로 승격하지 않았고 엔강대 문서는 수정하지 않았습니다. 같은 수행자의 검토이며 독립 모델 평가와 구분합니다.

테스트 76개·세 스킬의 형식 검사·패키지 참조와 파일 길이 검사를 통과했습니다. 회귀는 부모 페이드·자산 실패/대기·기하 변화·문맥·짧은/빈 관찰·큰 시간 공백·의도한 반투명·대체 화면·전환 방식·잘못된 입력·종료 코드·입력 보존을 포함합니다.
