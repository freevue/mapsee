## 검사기와 가상 자료

전체 테스트 47개가 통과했습니다. 대상 목록의 누락·잘못된 연결·중복·불충분한 complete, 이전 문제의 누락·미측정·검토·예외를 해결로 오판하는 경우와 기준·기대값·대상·방법·조건 변경을 확인했습니다. 비교 CLI의 입력 보존과 실패 출력도 확인했습니다.

기대 판정·검증기·테스트·이전 결과를 제공하지 않은 Codex가 설치 지침과 [스타일 자료](../../test/fixtures/style-overrides/DESIGN.md)를 읽었습니다. 높이·비활성·여백·색의 위반 4개, 허용된 너비 1개, plain 적용 제외 1개, 페이지 높이 불일치 1개와 제목 일치 1개로 판정했습니다. 계획 8개가 모두 기대 판정과 일치했고 미측정은 없습니다.

가상 자료의 대상 목록은 13개 중 확인 12·범위 밖 1입니다. 두 축의 일치율과 별개의 개수입니다. 소스만 확인한 정적 결과이며 실제 CSS 계산이나 브라우저 수용으로 표시하지 않았습니다.

정적 수행 전후 입력 26개의 해시가 같았습니다. 이후 이력 비교 도구가 빈 조건·식별 불충분 대상을 해결로 분류하지 않도록 추가 검증하고 설치본을 갱신했습니다. 정적 평가가 읽은 스킬·참조·집계기·가상 소스는 바뀌지 않았고, 이력 도구 자체의 변경은 별도 테스트로 확인했습니다. 검색 명령에 있는 테스트 제외 glob은 테스트 파일 열람과 구분했습니다.

## setup의 미결정 제안

기존 문서·구현과 미채택 제안을 구분했습니다. Rule·Dialog의 현재 초점 처리 부재는 현재 상태의 설명이며 자동 면제 규칙으로 취급하지 않았습니다.

모달 후보는 제목 진입·내부 Tab 순환·Escape/명시적 닫기·트리거 복귀·배경 차단을 연결했습니다. 닫힘 시작과 300ms 제거 사이의 기존 계약도 구분했습니다. 비모달 후보는 설정을 계속 편집할 수 있는 패널과 초점 비강탈·배경 허용 조건으로 제안했습니다.

중첩 반경은 실제 Rule 바깥 카드와 Rule/Card를 연결했습니다. 자식 padding과 부모·자식 사이 inset을 혼동하지 않았고, GlassCard가 Rule/Card의 직접 부모라고 가정하지 않았습니다. 독립 문단 면의 반경과 윤곽을 따르는 중첩 표면의 관계를 별도 후보로 제안했습니다. 특정 공식을 모든 카드에 채택하지 않았습니다.

제안은 미채택이며 setup은 부분 구성입니다. 실제 엔강대의 DESIGN·wiki·제품 코드는 수정하지 않았습니다.

## 실제 화면과 허용된 차이

이전 11개 항목을 새로 확인했습니다. 라벨 연결·A/B 초점 순서·빈 이름 제출 차단·생성 중 잠금·합성 실패 복구·규칙 창의 이름과 Escape, 준비 스텝의 제목·주요 버튼 표현은 이전과 같았습니다. 규칙 창의 초점 관리와 중첩 라운드의 기준은 계속 검토입니다.

추가한 대진표의 FormField·Input은 실제 라벨·ID와 연결되고 이름을 읽기 전용으로 유지했습니다. 홈의 편집 가능한 이름 입력과 다르다는 이유로 위반으로 만들지 않았습니다. 툴바의 공용 ActionButton은 실제 높이 48px였으며 DESIGN의 해당 역할 기준과 일치했습니다. 공용 기본값 64px를 모든 역할에 강제하지 않았습니다.

다른 URL의 주요 생성 행동은 Wanted Sans 계열·노랑 배경·어두운 글자로 같았습니다. 이름 입력의 중립 면·글자색도 같았습니다. 같은 URL의 준비 스텝 비교와 다른 URL의 두 항목을 따로 기록했습니다.

대진 생성 폼의 버튼은 높이 64px를 유지하지만 font-size 16px·padding 16px입니다. 홈과 공용 원천의 기본값은 20px·좌우 40px입니다. 실제 적용 CSS와 계산값을 확인했으며, 역할별 선택 근거가 충분하지 않아 새 검토 항목으로 남겼습니다. 코드에 차이가 있다는 이유로 문서를 코드에 맞추거나 확정 위반으로 만들지 않았습니다.

## 범위와 집계

대상 목록은 페이지 8·사용처 6·상태 3의 총 17개입니다. 확인 10·범위 밖 7·미검사 0입니다. 다른 URL 6개와 대진표의 실제 생성·성공 연결 상태가 범위 밖입니다. 두 대표 URL의 표본이며 전체 저장소의 모든 사용처를 발견했다고 주장하지 않습니다.

실제 보고서는 16개 항목입니다. 컴포넌트는 일치 8·검토 3으로 적합률 `8/8 = 100%`, 커버리지 `8/11 = 72.73%`입니다. 화면 간 비교는 일치 5로 `5/5 = 100%`, 커버리지 100%입니다. 선택한 검사에 미측정은 없으며 complete는 수집 완료를 뜻합니다.

0.7.0과의 비교 도구는 기존 판정 유지 11·추가 검사 5로 분류했습니다. 새 확정 불일치·해결·미재검사·기준 변경은 0입니다. 기존 검토 2개가 해결된 것은 아니며 이번 검토 1개가 더해졌습니다. 표본이 넓어져 커버리지가 달라졌으므로 두 버전 비율만으로 품질 변화를 주장하지 않습니다.
