# 맵시 1.0.0 배포 검증

2026-11-23에 0.12.0의 검사 동작을 고정해 Codex 우선 정식 버전을 검증합니다. 0.6.0 이후 누적 변경을 포함하며 실제 화면을 전부 다시 검사한 결과와 구분합니다.

## 범위와 근거 재사용

엔강대 입력은 0.12.0에서 사용한 develop 6919ed26874eaf79f2af95a77949c764c5a022f3입니다. 보존한 원본·기준·보고서·준비 기록을 설치본으로 다시 확인합니다. 새 브라우저·제품 서버·DB를 실행하지 않으며 제품·wiki·DESIGN을 수정하지 않습니다.

0.12.0 대비 두 plugin.json의 버전을 변경하고 호환성·배포 문서를 추가했습니다. 기존 플러그인 파일 37개는 바이트 단위로 동일하며 새 설치본 파일 40개도 후보 소스와 동일했습니다. 같은 원본으로 집계·근거 검증·준비 검사·이력 비교를 재실행했습니다. 같은 수행자의 검증이며 독립 모델 평가가 아닙니다.

실제 화면의 관찰·이미지·범위·한계는 [0.12.0 기록](0.12.0.md)을 보존합니다. 당시 실제 8항목은 일치 5·검토 3, 컴포넌트 적합률 100%·커버리지 57.14%, 페이지 표본 1개는 100%입니다. 이를 전체 프로젝트의 적합률로 해석하지 않습니다.
