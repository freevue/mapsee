## 엔강대 토큰과 선택 의미

ActionButton primary와 선택된 ChoiceGroup의 배경은 실제 var(--color-primary)에 연결됐습니다. 확인한 앱·공용 토큰 선언과 해결값은 #ffd215, 전경은 --primary-foreground의 #16181f였습니다. --primary 별칭도 같은 값으로 해결됐습니다. 해당 경로에서 활성 fallback은 확인되지 않았습니다.

원본 CSS Modules·앱 토큰·실제 요소에 대응하는 CSSOM 선언과 계산값을 함께 연결했습니다. 빌드 지시문과 실행 변수를 합쳐 순환으로 판정하지 않았습니다. 초기 CSSOM 후보에서 부모 문맥을 해석하지 않은 & 중첩 선택자는 제외했고, 이를 최종 캐스케이드 승자 분석기로 사용하지 않았습니다.

경기 방식은 방향키로 정식→레전드→공허사냥꾼으로 이동했습니다. 매번 native checked·선택 색·폼 값이 함께 바뀌었습니다. 공허사냥꾼에서는 관련 입력이 잠겼고 복귀 후 값·입력이 복원됐습니다. 기본적으로 비활성인 입력도 있어 전체 비활성 개수는 2→9→2입니다. 복귀 직후의 색 전환 중 기록은 보존하고 안정된 최종 복귀 자료를 따로 확인했습니다.

native radio에 aria-selected가 없다는 사실을 위반으로 만들지 않았습니다. 접근성 트리에서 radio 이름·checked 전달도 확인했습니다. 이는 화면 읽기 프로그램의 실제 음성 출력 검증이 아닙니다.

대진의 승리 버튼은 Space 전 false·idle·아이콘 없음, 선택 후 true·winner·승자 문구·체크 아이콘 1개로 바뀌었습니다. 해제 시 false·idle·아이콘 없음으로 복귀했습니다. 색 전환 중간값과 최종 상태를 구분했고 전체 대진 진행·DB 저장을 검증했다고 하지 않았습니다.

서로 다른 두 URL에서 같은 공개 ActionButton primary 변형의 색 참조와 해결값을 비교했습니다. 라디오·승리 토글의 행동 목적과 ARIA 패턴을 같게 요구한 비교가 아닙니다.
