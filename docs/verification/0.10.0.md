뷰포트와 실제 부모·content box·행동 너비를 각각 기록했습니다. 같은 뷰포트에서도 좁은 모달임을 구분했습니다. 특정 CSS 기능이나 작은 variant의 일괄 사용을 요구하지 않았습니다.

폼 최대 너비·화면 여백과 공용 버튼 높이 계약은 일치했습니다. 모달의 글자·여백 차이는 관찰했지만 역할별 채택 기준이 미확정이므로 기존 `CU-BRACKET-ACTION-OVERRIDE`를 review로 남겼습니다. 이 표본에서 잘림·과업 실패는 확인되지 않았으며 시각적 수용을 확정하지 않았습니다.

첫 본문 캡처는 조상 요소의 페이드가 끝나기 전에 촬영됐습니다. 초기 파일은 보존했고 조상 opacity가 1인 조건에서 다시 수집·확인한 자료만 최종 근거에 연결했습니다.

## 연속 상태 전환

| 흐름 | 관찰과 근거 |
| --- | --- |
| 참가자 입력 → 대기 | 입력·이전·제출이 잠기고 aria-busy=true. Enter 후에도 첫 생성 요청 1개 유지 |
| 합성 실패 → 이름 수정 | 이름 유지·입력 복구·오류 표시. B 이름을 수정하자 오류 제거 |
| 재시도 → 합성 성공 | 두 번째 요청에 수정한 이름 전달. 성공 ID·역할 정보 모형으로 같은 주소에 관리자·A·B 링크 3개 표시 |
| 대진 모달 대기 → Escape | 생성 요청 대기와 모달 열림 유지. 닫기 정책을 강제 클릭으로 우회하지 않음 |
| 대진 합성 실패 → Escape | 생성 결과 불명 안내 후 닫기 가능. 원래 카드의 경기 진행 버튼으로 초점 복귀 |
| 접속 조회 대기 → 새 방 → 늦은 응답 | 조회 4개를 보류한 채 경기 선택 화면으로 이동. 이후 4개 응답을 해제해도 이전 이름·링크가 새 화면을 덮어쓰지 않음 |

초기 지연 조회 스크립트는 요청이 정확히 2개라고 가정해 대기 조건이 실패했습니다. 실제 기록은 4개였습니다. 최초 스크립트와 진단을 보존하고 현재 페이지를 확인한 뒤 관측된 4개의 도착·해제를 기록했습니다. 이를 제품 오류나 생성 요청 중복으로 판정하지 않았습니다.

이탈 검사는 같은 문서 안의 화면 전환입니다. 네트워크·서버 요청의 실제 취소, 전체 문서 이탈이나 동시 요청 A/B 응답 역전은 검증하지 않았습니다. 합성 성공을 DB 저장 성공으로 해석하지 않습니다.

## 원본과 집계

캡처 색인 6개와 보존한 기준 파일 6개를 원본 묶음 version 1로 구성했습니다. 설치된 verify-evidence.mjs로 파일 해시·JSON Pointer·내용·문맥과 보고서 참조 10개를 대조해 issues 0을 확인했습니다. 색인의 관찰 높이만 바꾼 복사본은 원본 내용 불일치와 종료 코드 2를 반환했습니다. 원본은 보존했습니다.

같은 설치본의 summarize.mjs에서 대상 6개 모두 checked, pending 0·bindingIssues 0입니다. 현재 표본은 컴포넌트 일치 5·검토 1로 적합률 `5/5 = 100%`, 커버리지 `5/6 = 83.33%`입니다. 다른 URL의 공용 주요 행동 높이 비교 1개는 일치율·커버리지 100%입니다. 높이 외 표현 전체의 일치를 뜻하지 않습니다.

총 7항목 중 새 검사 6개·기존 검토 1개입니다. 이전 보고서와의 이력에서는 추가 6·기준/조건 변경 1·미재검사 20으로 나뉩니다. 해결 0입니다. 이전 Dialog 초점·중첩 반경 검토는 이번에 재검사하지 않았으며 해결 처리하지 않았습니다. 표본이 달라 이전 비율과 품질 증감을 비교하지 않습니다.

## setup과 코드 검증

엔강대의 기존 DESIGN·참가자 입력·접속 링크·대진 연결 문서를 읽기 전용으로 대조했습니다. 최대 너비·잠금·복구·이전 조회 무시 기준은 원본으로 연결했고 모달의 글자·여백 정책은 미결정으로 남겼습니다. 제품 문서와 wiki는 수정하지 않았습니다.

별도 가상 문서 3개에서는 현재 Codex가 설치된 setup을 따라 기존 가이드 1개에 확정된 부모 너비·variant·연속 동작과 출처를 보완했습니다. 관찰한 12px 도구 모음은 미결정으로 보존하고 공개 props 계약은 링크했습니다. 같은 입력으로 다시 검토한 뒤 3개 문서 해시가 유지됐습니다. 이는 같은 수행자의 재검토이며 별도 모델의 독립 평가가 아닙니다. 가상 프로젝트 구현·공개 import 경로·실제 화면은 제공되지 않아 setup 전체 수용은 미검증입니다.

테스트 69개와 세 스킬의 형식 검사가 통과했습니다. 원본·CLI 검사는 파일·기준·내용·Pointer·참조 오류, 외부 경로·심볼릭 링크, 기존 입력 보존과 종료 코드를 포함합니다. 원본 검사 통과로 미측정·incomplete를 승격하지 않는 것도 확인했습니다.
