## 단위 검사와 독립 평가

테스트 59개가 통과했습니다. 기존 검사 ID의 존재만 확인하면 다른 URL·상태의 근거로 완료를 표시할 수 있던 경우를 먼저 재현했습니다. 강화 모드에서 URL·요소·상태·화면 조건·기준 식별자·수집 ID·대상 참조가 다르면 pending으로 남기고 complete를 거부하도록 확인했습니다.

공통 원인 묶음과 다른 원인의 혼합 거부, 과업 영향과 review의 분리, 미분류 보존, 재검사 대상·미연결 변경·표본 밖 영향·입력 보존도 검사했습니다. 이전 형식은 그대로 읽으며 강화 연결 검증으로 승격하지 않습니다.

평가할 Codex에 합성 보고서·원시 캡처·기준·변경 목록만 제공했습니다. 기대 판정·테스트·검증기·이전 결과는 제외했습니다. 확인 가능한 높이 불일치 1개를 유지하고 다른 페이지와 처리 중 상태의 근거가 없는 측정 2개는 not-measured로 남겼습니다. 관찰값을 null로 바꾸고 원본 캡처·기준·ID를 보존했습니다.

파생 보고서는 incomplete이며 대상 확인 1·pending 2입니다. 확인된 관계의 재검사 대상 3개와 미연결 변경 1개도 남겼습니다. 이는 합성 메타데이터 평가이며 실제 브라우저 검증이 아닙니다. 평가 입력·설치 자료 29개는 수행 전후 해시가 같았습니다.

## 대상·상태·근거 연결

원시 DOM·조작 자료에서 URL·상태·요소·뷰포트를 기록했습니다. 파생 수집 색인 21개에 원시 JSON 위치·파일 해시·수집 ID를 연결했습니다. 각 판정은 읽은 기준 파일의 해시와 실제 대상 ID·근거를 연결합니다.

수행자가 수집 색인의 데이터와 원시 JSON의 해당 위치·해시, 기준 파일 해시를 대조했습니다. 일부 초기 폼 수집의 URL·상태 누락은 새로 수집했고, 전환 중 규칙 창 이미지는 보존한 뒤 전환 완료 조건에서 다시 확인했습니다. 초기 자료와 최종 근거는 분리했습니다.

강화 연결에서는 대상 26개 중 확인 19·범위 밖 7·pending 0, bindingIssues 0입니다. 여기에는 페이지·사용처·상태라는 서로 다른 단위가 포함됩니다. 연결 메타데이터의 정합성이지 집계기가 원본 진위를 자동 보증한 결과는 아닙니다. 실제 보고서의 한 대상 URL을 바꾼 검증에서는 pending 1개를 남겼습니다.

실제 보고서는 기존 16개와 추가 5개의 총 21개 항목입니다. 컴포넌트는 일치 13·검토 3으로 적합률 `13/13 = 100%`, 커버리지 `13/16 = 81.25%`입니다. 화면 비교는 일치 5로 일치율·커버리지 100%입니다. 선택한 범위의 complete는 수집 완료이며 전체 서비스 통과가 아닙니다.
