# 맵시 1.1.0 검증

2026-11-27에 1.0.0과 호환되는 검사 지침·격자 시각화 도구를 1.1.0으로 묶습니다. 두 플랫폼의 plugin.json 버전을 맞추고 기존 보고서·CLI 계약을 유지합니다. 원시 기록·패키지·설치본 대조는 로컬 `.git/mapsee-release-1.1.0/`에 보존합니다.

## 기능 근거

[격자·다이얼로그 가상 검증](grid-surfaces.md)은 이번 대화에서 작성한 도구와 가상 화면의 실제 브라우저 결과입니다. 두 뷰포트·네 상태의 8개 표본에서 의도한 14px 간격은 mismatch, 왼쪽 정렬과 기준점은 match였습니다. 입력·PNG 보존과 오류→재시도→모의 성공, 닫은 뒤 초점 복귀를 확인했습니다. 설치본 실행으로 바꿔 기록하지 않습니다.

현재 미배포 소스로 공개 `https://ncore.freevue.dev/`와 `/hall-of-fame`도 새로 검사했습니다. 1440×900·390×844·320×740에서 선택한 홈·설정·룰 창·전당 상세·라운드 탭을 확인했습니다. 제품·운영 데이터는 수정하지 않았습니다.

표본 14개는 일치 8·검토 5·미측정 1입니다. 컴포넌트는 일치 7/7, 커버리지 7/12=58.33%이며 페이지는 일치 1/1, 커버리지 1/2=50%입니다. 대상·상태 연결 문제는 0개이고 원본 근거 22개·기준 7개·보고서 참조 22개의 검사는 verified, issues 0입니다. 실제 자료는 로컬 `.git/engangdae-audit-20261127/`에 보존하며 공개 패키지에 포함하지 않습니다.

좁은 화면의 선택 이름 분리·전당 프로필/수치 겹침·룰 창의 배경 초점 이동·제목 크기 차이는 검토로 남겼습니다. 선택한 격자 관계는 12px·8px·정렬 차이 0px이나 기존 전체 화면의 강제 4px 기준은 미확인입니다. 전당 탭의 불필요한 제목 반복과 선택한 기본 화면의 임시 검사 문구·로그는 관찰하지 못했습니다. 전수 부재를 보증하지 않습니다.

로컬 엔강대 기준 HEAD는 6919ed26874eaf79f2af95a77949c764c5a022f3이며 공개 배포 SHA는 미확인입니다. 일부 공개 DOM과 로컬 소스가 달라 로컬 문서를 현재 배포의 형상으로 단정하지 않았습니다. 서버 요청의 처리 중·오류·재시도는 운영 방 생성·저장을 실행하지 않아 미측정입니다.
