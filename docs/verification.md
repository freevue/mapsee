# 맵시 구성·검증 기록

맵시의 개발 검사·가상 프로젝트 평가·설치본 수행·실제 프로젝트 검증을 구분해 기록합니다. 아래 요약은 0.6.0의 최종 결과이며, 이후 절은 각 단계에서 수행한 범위와 보완 과정을 보존합니다.

## 0.6.0 변경과 최종 검증 요약

setup은 기존 DESIGN·컴포넌트 가이드의 유무·누락·최신성·충돌을 점검하고 보완합니다. lint는 컴포넌트 선택·배치·간격·중첩 라운드에 상태·오류 복구·키보드·콘텐츠·환경 변화 검사를 더했습니다. 기준의 채택 근거와 재현 조건을 연결하고, JSON 필드 타입과 미측정의 실행 상태를 명확히 했습니다. 검사 결과를 받는 도구가 후속 수정을 결정하는 보고 전용 경계는 유지합니다.

| 검증 | 최종 결과 | 판단 범위 |
| --- | --- | --- |
| Node.js 검사기·패키지 테스트 | 23개 통과 | 산식·입력 보존·예외·누락·오판·근거 종류·종료 코드 |

엔강대의 통합 계획 23개는 일치 22·판단 필요 1·미측정 0으로 수집을 마쳤습니다. 컴포넌트 적합률은 `16/16 = 100%`, 커버리지는 `16/17 = 94.12%`입니다. 페이지 간 정적 일관성은 `6/6 = 100%`, 커버리지는 `6/6 = 100%`입니다. 기준이 미확정인 중첩 라운드는 판단 필요를 유지합니다. 계획 밖의 `text-base` 두 위치와 넓은 화면의 저작권 문구·버튼 겹침은 별도로 보고했으며 제품을 수정하지 않았습니다.

실제 DB 저장·운영 서버·물리 기기·보조 기술·전체 경기 E2E의 수용 검증은 포함하지 않습니다. 이 문서에는 공유 가능한 범위·판정·한계를 정리하고, 실제 프로젝트의 원시 소스·화면·실행 로그는 아래 로컬 실행 폴더에 보존했습니다. 재현용 공개 가상 화면과 검사 절차는 [검증 준비](verification-plan.md)에 있습니다.

## 독립 적용

별도 에이전트에 [가상 프로젝트](../test/fixtures/component-consistency/DESIGN.md)와 lint 스킬을 제공했습니다. 요청은 검색 화면의 컴포넌트 사용과 설정 화면의 동등한 UI를 정적 소스로 비교하는 것이었습니다. 기대 답이나 의심 결함은 제공하지 않았습니다.

호출부를 읽기 전에 검사 항목 11개를 고정했습니다. 독립된 문제 원인은 다음 3개입니다.

| 문제 | 관찰과 기준 |
| --- | --- |
| 주요 버튼의 역할과 변형 불일치 | 검색은 `secondary`, 주요 제출 기준과 설정은 `primary` |
| 페이지 CSS의 공용 높이 덮어쓰기 | 검색은 `36px`, 공용 기준과 설정은 `40px` |
| 두 페이지가 공유하는 라벨 기준 위반 | 두 페이지는 서로 같은 `12px`를 사용하지만 기준은 `14px` |

컴포넌트 적합률은 `2/5 = 40%`, 페이지 일치율은 `3/5 = 60%`였습니다. 두 축의 커버리지는 각각 `5/5 = 100%`이며 고유 소개 영역의 예외 1개를 페이지 비교 분모에서 제외했습니다. 이는 이 가상 프로젝트에서 정한 정적 항목의 결과입니다.

같은 라벨 값을 페이지 일치로 집계하면서 공용 사용 위반도 별도로 지적했습니다. 두 축에 나타난 같은 원인을 독립된 결함으로 중복 집계하지 않았습니다. 공개 API가 허용하는 변형과 실제 역할에 맞는 변형도 구분했습니다.

제공된 `summarize.mjs` 실행은 종료 코드 0이었습니다. 원본과 집계 결과의 항목 보존, 계획·보고 ID 11개 일치, 입력 11개 SHA-256의 검사 전후 불변을 확인했습니다. 입력 프로젝트와 스킬은 수정하지 않았습니다.

## 확인하지 않은 범위

서버·브라우저·네트워크·페이지 함수를 실행하지 않았습니다. 실제 렌더, 계산된 스타일, 글꼴·자산 로딩, 해상도·테마별 배치와 조작 수용은 검증하지 않았습니다. 선택한 정적 항목의 커버리지 100%를 이 범위의 통과로 확대하지 않습니다.

Claude·Codex 클라이언트에 플러그인을 설치해 선택·수행하는 절차는 이번 검증 범위에 포함하지 않았습니다. 수집 도구의 가용성과 실제 화면 상태는 적용하는 프로젝트와 실행 환경에서 확인해야 합니다.

## 2026-11-22 로컬 스킬 확장 검증

배포 전 소스에서 setup의 기존 문서 상태 점검·보완, 간격·중첩 라운드·배치·선택 이유, 상태와 조작 및 콘텐츠·환경 변화 검사 지침을 보완했습니다. 기준의 채택 근거와 재현 조건·기대 결과를 연결하고, 계획과 실제 관찰 조건·휴리스틱 의견·미측정을 구분했습니다.

- `node --test test/*.test.mjs`: 15개 통과. CLI 사례에 조건·환경·개별 결과의 전달 보존과 판단 필요·미측정의 집계 확인을 추가했습니다.
- skill-creator `quick_validate.py`: setup·document·lint 3개 형식 통과. 로컬 YAML 의존성은 기존 uv 오프라인 캐시를 사용했고 프로젝트 의존성은 추가하지 않았습니다.
- 보고서 가상 예시 8개 항목에서 컴포넌트 일치율 `1/2 = 50%`, 커버리지 `2/4 = 50%`를 확인했습니다. 페이지 일치율은 `1/2 = 50%`, 커버리지는 `2/3 = 66.67%`이며 적용 제외 1개를 분모에서 뺐습니다.

이는 지침·패키지·보고서 전달과 집계 검증입니다. 신규 항목으로 실제 프로젝트의 화면·키보드·보조 기술·환경 전환을 검증한 결과는 아닙니다. 해당 소스의 배포·설치본 갱신과 새 클라이언트 수행도 이번 검증에 포함하지 않았습니다. 앞의 2026-11-18 가상 적용 기록은 당시 범위의 별도 근거입니다.

## 확장 검증 자료 준비와 가상 화면 구동

[검증 절차](verification-plan.md)와 가상 화면 2종, 검사 ID 17개, 별도로 분리한 기대 판정, 보고서 검사 명령을 추가했습니다. 결과 검사기의 추가 테스트 7개를 포함해 총 22개가 통과했습니다. 미측정은 `pending`과 종료 코드 2로 남기고, 오판·누락·근거 부족은 종료 코드 1로 구분합니다.

Ego Lite의 Chromium 환경에서 가상 화면을 직접 조작하고 DOM을 확인했습니다. 대상 화면은 비교 화면과 달리 간격 `12px/8px`, 안쪽 반경 `24px/16px`, 터치 영역 `20px/40px`, 320px 뷰포트의 문서 폭 `656px/320px`, 지연 안내 뒤 위치 이동 `80px/0px`를 보였습니다. 오류 시 메모 소실·초점 미이동과 모달의 잘못된 초점·Escape 동작도 재현했습니다.

비교 화면의 Tab이 브라우저 영역으로 나가는 동작을 발견해 닫기 버튼 하나인 검증용 모달의 초점 처리를 보완했습니다. 수정 후 Tab·Shift+Tab 유지와 Escape 종료·열기 버튼으로의 초점 복귀를 확인했습니다. 움직임 감소 설정은 화면 이동 후 다시 적용해 양쪽의 실제 media 조건과 계산된 애니메이션 이름을 확인했으며 시간에 따른 프레임 변화까지 검증한 것은 아닙니다.

원시 관찰과 재현 조건은 로컬 `.git/mapsee-audit-preparation-20261122-*` 실행 폴더에 보관했습니다. 직접 만든 가상 화면의 구동 확인으로, 맵시를 실행한 독립 평가나 새 설치본의 Claude·Codex 검증은 아닙니다. 실제 제품·보조 기술·전체 시각 수용은 미검증입니다. 띄운 서버와 브라우저 작업 공간은 종료했습니다.

## 2026-11-22 mapsee 0.6.0 설치본 수행

소스 버전을 0.6.0으로 구분하고 두 클라이언트에 로컬 후보를 설치했습니다. 설치된 파일 15개는 소스와 SHA-256이 일치했습니다. Codex는 기존 `mapsee@mapsee` 등록을 유지했고, Claude는 `mapsee@mapsee-local`을 설치·활성화하고 중복 로딩을 막기 위해 이전 0.5.0을 비활성화했습니다. 설치 검증은 GitHub 반영 전 로컬 후보로 수행했습니다.

Codex CLI 0.155.1의 새 실행에서 설치 캐시의 setup·lint를 읽은 기록을 확인했습니다. 사용자 설정을 변경하지 않고 실행별 기본 설정을 사용했습니다. 기대 판정·검증기·과거 결과는 평가 입력에서 제외하고 실제 명령 기록에서도 해당 파일을 읽지 않았는지 확인했습니다.

- setup 점검은 기존 문서와 끊긴 상세 가이드 연결, 관찰과 확정 기준·허용 예외를 구분했습니다. 별도 복사본의 보완 실행은 DESIGN·컴포넌트 문서 두 개만 수정했고, 기존 확정 기준·나머지 입력·파일 구성을 보존했습니다. 출처·재현 조건을 보완하고 모르는 원본은 복원했다고 꾸미지 않았으며 부분 구성으로 보고했습니다.
- 첫 lint 실행은 macOS 브라우저 연결이 중첩 샌드박스에 막혀 미측정을 남겼습니다. 결과 검사 명령도 `pending`, 종료 코드 2를 반환했습니다. 현재 허용된 로컬 실행 환경에서 다시 실행한 실제 화면·키보드·시간 관찰은 17개 항목의 기대 판정과 일치했습니다.
- 최초 화면의 제목·버튼이 중첩 표면 안쪽 거리 측정에 섞이는 점을 발견해 fixture를 보완했습니다. 새 입력으로 다시 17개 전체를 실행해 기대 판정 일치·미측정 0개를 확인했습니다. 중첩 표면의 실제 네 방향 거리는 모두 `8px`였습니다. 각 실행 전후의 스킬·fixture 입력 21개 해시는 동일했습니다.
- 허용된 pill을 `not-applicable`로 보고한 올바른 판단을 검증기가 오판으로 세는 문제를 재현·수정했습니다. 직접 사용의 `match`와 중첩 규칙의 근거 있는 `not-applicable`을 모두 인정하며, 위반 판정은 거부합니다. 회귀 테스트를 포함한 최종 테스트 23개가 통과했습니다.

최종 가상 화면은 컴포넌트 불일치 13·판단 필요 1·적용 제외 1, 페이지 비교 일치 1·불일치 1입니다. 이는 의도한 결함과 예외를 식별한 결과이며, 페이지 일치율이나 검증기의 일치를 제품 전체 품질로 확대하지 않습니다. 실제 모바일 기기·보조 기술·전체 시각 수용과 엔강대의 신규 항목 재검사는 포함하지 않았습니다.

Claude Code 2.1.87은 설치·활성화와 파일 동일성까지 확인했으며 로그인 부재로 실제 setup·lint 실행은 남았습니다. 로컬 실행 기록은 `.git/client-verification-20261122-pd403nbs/`에 보관했습니다. 직접 띄운 서버와 브라우저 작업 공간은 종료했습니다. 형식·패키지 검사와 가상 프로젝트의 클라이언트 수행, 실제 제품 검증은 각각 별도 근거입니다.
