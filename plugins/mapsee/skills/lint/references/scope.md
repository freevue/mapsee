# 대상 목록과 페이지 비교

대상 목록은 무엇을 발견했고 검사했는지 설명합니다. 두 검사 축의 적합률과 다른 정보이며 전체 저장소를 자동 탐색하는 분석기는 아닙니다.

## 탐색과 누락

라우트 선언·공개 export·import와 실제 호출부를 현재 프로젝트의 검색 도구로 찾습니다. 대상의 실제 렌더 분기까지 따라가고 같은 공용 컴포넌트의 구현 내부는 호출부와 구분합니다. 검색한 폴더·파일 종류·동적 경로·접근 제한을 `scope.discovery`에 적습니다. 정적 문자열 검색만으로 동적 렌더와 모든 사용처를 찾았다고 하지 않습니다.

요청 범위의 발견 대상을 `scope.inventory`에 연결합니다. 각 항목은 아래 필드를 가집니다. 프로젝트 전체를 요청받지 않았다면 요청 밖의 전체 목록을 수집할 필요는 없습니다.

| 필드 | 내용 |
| --- | --- |
| id | 대상의 고유 ID |
| kind | page, usage, state 중 대상 종류 |
| path·role | URL 또는 실제 호출부 경로와 역할 |
| disposition | inspect 또는 out-of-scope |
| findingIds | 해당 대상을 확인한 검사 ID 배열. 아직 계획하지 못했으면 빈 배열 |
| reason | 범위 제외 이유. 디자인 규칙의 적용 예외와 혼동하지 않음 |

실행 전에는 대상별 예정 검사 ID를 정하고, 실행 후에는 동일한 ID의 결과를 남깁니다. 선택한 대상을 재현하지 못하면 `not-measured`를 남깁니다. 목록에서 삭제해 검사율을 높이지 않습니다. 기준이 불충분해 조사 후 `review`로 남긴 대상도 조사 여부와 적합성 판정을 구분합니다.

집계기는 inventory가 있을 때 `inventorySummary`에 발견·확인·미검사·범위 밖의 개수를 별도로 출력합니다. 확인은 연결한 검사 전부의 결과가 있고 미측정이 없는 경우입니다. 검토나 적용 제외가 남아도 확인한 대상일 수 있으며 제품 적합성을 뜻하지 않습니다. 빈 계획·미측정 연결이 남으면 실행 상태는 incomplete입니다. 목록 자체가 없는 이전 보고서에서 누락 확인을 했다고 추정하지 않습니다.

새 수집에서는 [강화된 대상 연결](quality.md#강화된-대상-연결)로 실제 대상·상태·조건·기준 식별자를 대조합니다. 이전 형식의 검사 ID 연결만으로 같은 수준의 근거 검증을 했다고 하지 않습니다.

## 실제 페이지 간 비교

비교할 URL과 화면 상태를 따로 기록합니다. `scope.comparisons`의 target·reference는 실제 소스/화면을 식별하고, conditions에 URL·상태·화면 크기·테마·포인터/초점·전환 조건 중 관련 값을 연결합니다.

같은 역할과 계약을 공유하는 입력·행동·카드·오류 등을 비교합니다. 검색과 관리 화면처럼 밀도·영향·역할이 다르면 허용된 차이의 근거를 확인합니다. 준비 화면의 여러 스텝 비교를 다른 URL까지 검사한 결과로 표시하지 않습니다. 로그인·데이터가 필요한 비교는 제공된 테스트 자료나 재현 가능한 범위만 확인합니다.

각 쌍에 비교 이유·공통 역할·양쪽 위치·원본 규칙·실제 값을 남깁니다. 다른 페이지도 같은 값을 쓴다는 이유만으로 옳다고 하지 않습니다. 두 페이지가 같은 방식으로 계약을 어겼으면 직접 사용의 위반과 화면끼리의 일치를 각각 보고합니다.

## 스타일 덮어쓰기

공용 컴포넌트를 사용했다는 사실과 표현 계약의 준수는 따로 검사합니다. 컴포넌트가 고정한 높이·여백·색·타이포그래피·disabled/hover/focus 상태를 앱 클래스·인라인 스타일·상위 선택자가 바꾸는지 확인합니다.

선택자 우선순위·CSS 순서·변수·상속·미디어 조건과 실제 사용 위치를 대조합니다. 정적 선언만으로 우선순위나 동적 조건을 확정할 수 없으면 계산된 스타일·원본 CSS·대상 상태를 확인하거나 미측정으로 남깁니다. 클래스 이름의 외형만 보고 판정하지 않습니다.

공개 plain/unstyled 변형, 호출자가 소유하는 너비·배치·역할별 크기와 문서화된 예외는 허용합니다. 모든 override를 위반으로 만들지 않습니다. 기준·호출부·원천 스타일과 기대/관찰 차이를 연결하고 중복 근거는 한 문제에 모읍니다.
