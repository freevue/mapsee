# 다이얼로그·영역과 상태별 화면 검사

URL 하나를 화면 하나로 간주하지 않습니다. 다이얼로그·드로어·팝오버·다단계 폼은 URL·호출부·실제 영역·상태·화면 조건을 조합해 검사 대상을 식별합니다. 기존 inventory의 usage·state와 binding을 사용하며 새 필수 보고서 형식이나 검사 축을 만들지 않습니다.

## 대상과 상태 계획

1. 여는 버튼과 실제 표시되는 영역을 연결합니다. 포털은 트리의 부모 위치를 가정하지 말고 role·접근 가능한 이름·실제 요소로 찾습니다. 같은 다이얼로그가 다른 페이지·호출부에서 쓰이면 공용 구현과 사용처별 차이를 구분합니다.
2. 적용 가능한 기본·빈 내용·처리 중·오류·완료·비활성 상태를 고르고 재현할 입력·조작·응답을 계획합니다. 실제로 없는 상태를 의무화하지 않으며 사용자 요청·공통 계약·관찰 가능한 위험에서 우선순위를 정합니다. 선택 상태별 검사 ID와 재현하지 못한 항목을 보존합니다.
3. 데스크톱·좁은 뷰포트와 실제 컨테이너 크기, 긴 문구·오류 메시지·스크롤 조건 중 필요한 조합을 선택합니다. 물리 모바일 키보드와 합성 표시 영역은 [모바일 기준](mobile-viewport.md)으로 구분합니다. 전수 조합 검사라고 주장하지 않습니다.

## 상태마다 남길 화면

| 근거 | 확인할 내용 |
| --- | --- |
| 전체 뷰포트 캡처 | 화면 밖 잘림·배경 가림·레이어·고정 영역과의 충돌·다른 UI의 접근 |
| 영역 캡처와 실제 경계 | 제목·본문·입력·오류·푸터의 관계, 부모 여백·줄바꿈·간격·스크롤 |
| 상태·조작 기록 | 값·오류·disabled·선택·초점, 요청 도착과 응답 순서, 열기·닫기·복귀 |

영역만 잘라 보면 잘림·주변 충돌을 놓칠 수 있으므로 전체 화면도 연결합니다. 반대로 전체 캡처 하나로 작은 영역의 간격을 측정했다고 하지 않습니다. 준비된 정지 상태에는 [격자와 측정선](grid.md)을 사용할 수 있으며 상태마다 같은 기준점 정의·관계 ID를 유지합니다. 중간 상태가 준비되지 않았다는 이유로 기본·완료 화면으로 대체하지 않습니다.

## 상태 사이의 변화

[연속 전환](transitions.md)의 sequenceId·실제 조작·응답 순서를 연결합니다. 같은 상태의 캡처 비교와 시간 순서의 검증을 구분합니다.

- **열기·닫기:** 첫 초점·Tab 이동·Escape·바깥 클릭의 정책, 배경 스크롤과 닫은 뒤 초점 복귀를 실제 조작으로 확인합니다. 대기 중 닫기를 허용하는지 원본 계약을 먼저 봅니다.
- **기본 → 처리 중:** 버튼·푸터의 위치와 크기, 입력 잠금·중복 제출 방지·진행 안내가 계약대로 바뀌는지 확인합니다.
- **처리 중 → 오류 → 수정·재시도:** 오류 추가에 따른 제목·입력·버튼 위치·영역 높이·줄 수의 변화와 입력·스크롤·초점 보존·복구를 확인합니다.
- **완료·이탈·늦은 응답:** 완료 상태의 안내·다음 행동, 떠난 영역에 늦은 응답이 내용을 되살리는지 확인합니다. 모의 성공은 실제 저장 성공으로 보고하지 않습니다.

상태에 맞춰 높이·배치가 자연스럽게 바뀌는 것 자체는 오류가 아닙니다. 실제 경계 변화와 조작 영향, 프로젝트의 유지·재배치 계약을 대조합니다. 고정 높이나 오류 영역 예약을 일괄 강요하지 않습니다. 정지 PNG만으로 초점 이동·중복 요청·복구 순서를 통과시키지 않습니다.

## 보고

예를 들어 `/settings`의 `#profile-dialog` 오류 상태는 inventory의 state 항목으로 기록하고 해당 사용처·상태·뷰포트·컨테이너를 binding에 연결합니다. 기본과 오류에 같은 근거를 재사용하지 않습니다. 같은 URL의 상태 비교는 component-usage이며 서로 다른 페이지의 동등한 사용처 비교만 page-consistency로 집계합니다.

원본 캡처·경계 JSON·격자 SVG·준비 기록·조작 순서는 별도 근거로 연결합니다. 측정값이 같아도 상태별 수집이 빠졌으면 완료하지 않습니다. 기준 미정은 review, 계획한 상태의 재현 불가는 not-measured입니다. 화면 검사 권한을 실제 저장·삭제·운영 데이터 변경 권한으로 확대하지 않습니다.
